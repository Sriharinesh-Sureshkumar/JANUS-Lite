Pipeline architecture

Two specialized agents, one verification contract

01

Triager

First-line agent

Reads raw bug reports from any source. Checks the bugs table for duplicates before creating a new investigation. Writes a concrete hypothesis and assigns confidence — uncertain reports route to human review instead of proceeding automatically.

  • Deduplicate across GitHub, Slack, email
  • Confidence scoring (high / medium / low)
  • Routes uncertain cases to needs_human_review
  • Outputs structured JSON only — never writes directly to table
Claude Sonnet Pod workspace JSON output only
02

Verifier-Fixer

Second-line agent — sandboxed

Clones the target repository into an isolated sandbox. Pre-searches the codebase using keyword extraction before writing any test. Runs ruff and bandit as a parallel static analysis layer. Never claims success on model confidence — only on a passing test.

  • Keyword locator (ripgrep, 10-line context windows)
  • Static analysis: ruff + bandit on every run
  • Writes real failing reproduction tests
  • 3-attempt retry loop with error feedback
  • Honest escalation — never fabricates a fix
  • Auto-opens GitHub PR on verified fix
WORKSPACE_CLI ruff + bandit 3-attempt retry
The contract

"No fix ships without mechanical proof. If JANUS-Lite cannot produce a failing test that passes after the patch, it does not open a PR — it escalates honestly with the full evidence trail."
